# House Price Prediction

## 📌 Project Overview

This project uses Machine Learning regression techniques to predict median house values based on different housing and demographic features.

Two Machine Learning models are trained and compared:

* Linear Regression
* Random Forest Regression

The project was developed and tested using **Google Colab**.

## 🎯 Project Objectives

* Explore the housing dataset
* Clean and prepare the data
* Analyze relationships between variables
* Identify important features
* Train regression models
* Predict house values
* Compare model performance
* Evaluate prediction errors

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## 🤖 Machine Learning Models

### Linear Regression

Linear Regression is used as a baseline model to predict house values based on the available features.

### Random Forest Regression

Random Forest Regression uses multiple decision trees to capture more complex relationships in the data.

## 📈 Model Evaluation

The models are evaluated using:

* **MAE (Mean Absolute Error)**
* **RMSE (Root Mean Squared Error)**
* **R² Score**

The notebook automatically calculates and compares these metrics.

## 🏆 Model Comparison

The project compares Linear Regression and Random Forest Regression to determine which model provides better prediction performance based on the evaluation metrics.

The best-performing model is selected automatically using the **R² score**.

1. Open `House_Price_Prediction.ipynb` in **Google Colab**.
2. Run the notebook from beginning to end.
3. The California Housing dataset is loaded automatically.
4. The data is cleaned and analyzed.
5. Both Machine Learning models are trained.
6. The models are evaluated and compared.
7. Predictions and visualizations are generated.
